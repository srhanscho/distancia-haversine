# Distancia entre dos puntos de la Tierra (haversine)

Demo para la actividad de trigonometría esférica. Calcula la distancia entre dos puntos A y B a partir de su latitud y longitud usando la fórmula del semiverseno (haversine), y la compara con la ley esférica de los cosenos y con un cálculo plano.

No usa librerías externas, solo las funciones de `Math` de JavaScript.

## Estructura

- `index.html`: interfaz
- `css/estilos.css`: estilos
- `js/geo.js`: funciones de cálculo (haversine, ley de cosenos, rumbo, punto intermedio)
- `js/app.js`: lectura del formulario, resultados y dibujo del mapa

## Uso

Abrir `index.html` en el navegador. También se puede abrir con `index.html#0,7` para cargar dos lugares de la lista (por posición).
